# Homework 02: program that computes $\vec{d} = a \vec{x} + \vec{y}$

This program computes the vector operation

$$
d_i = a x_i + y_i
$$

for three vector sizes:

- `N = 10`
- `N = 10^6`
- `N = 10^8`

## What the code does

The program reads `a`, `x`, and `y` from the command line. Since all elements of the vectors `X` and `Y` are the same, it fills the vectors with constant values. Then it computes each element of `D` using:

```c
D[i] = a * X[i] + Y[i];
```

## Main parts of the code

- `fill_vector(...)` fills a vector with the same value in every position.
- `compute_sum(...)` computes the vector sum `D = aX + Y`.
- `check_vector(...)` checks that every element of `D` is equal to the expected value `a*x + y`.
- `run_case(...)` runs the computation for one specific size `N`.
- `main(...)` reads the inputs and runs the program for the three requested sizes.

## Specific example

The homework asks to test:

- `a = 3`
- `x = 0.1`
- `y = 7.1`

For these values, the expected result is:

$
ax + y = 3 \cdot 0.1 + 7.1 = 7.4
$

The program prints this value and checks that all elements of the vector `D` match it.

## Possible problem for large N

For very large vectors, especially `N = 10^8`, the program may need a lot of memory. Since the code creates three vectors of type `double`, the memory usage can become very large, and allocation may fail on some computers.
