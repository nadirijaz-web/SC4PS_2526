# Homework 03 — Matrix Multiplication

## What the program does
This C program solves the matrix multiplication

$$
C = AB, \qquad C_{ij} = \sum_{k=0}^{N-1} A_{ik} B_{kj}
$$

for the special case

$$
A = a\,\mathbf{1}_N, \qquad B = b\,\mathbf{1}_N,
$$
where every entry of `A` is `a` and every entry of `B` is `b`.

The program:

- reads `a`, `b`, `N`, and `fileout` from the command line
- builds matrices `A` and `B`
- computes `C = AB` using triple-loop matrix multiplication
- benchmarks all 6 possible loop orderings
- checks whether the result is correct
- saves matrix `C` to the output file

## Mathematical result
Since every element of `A` is `a` and every element of `B` is `b`, each entry of `C` is

$$
C_{ij} = \sum_{k=0}^{N-1} a b = N a b.
$$

So the output matrix is constant:

$$
C = (Nab)\,\mathbf{1}_N.
$$

This is the expected result used for verification.

## How correctness is checked
There are two checks in the code.

### 1. Quick verification
Instead of comparing every entry one by one, the program first checks:

- the sum of all entries
- the sum of squares of all entries
- one anchor element

For a constant matrix with value `N*a*b`, these quantities must match the expected values. This is a fast way to check correctness.

### 2. Full verification
The program also performs a full check by comparing every element of `C` with the expected value `N*a*b`.

## Benchmark: which loop ordering is fastest?
The code tests all 6 loop orderings:

- `i-j-k`
- `i-k-j`
- `j-i-k`
- `j-k-i`
- `k-i-j`
- `k-j-i`

In C, matrices are stored in **row-major order**. This means elements in the same row are stored next to each other in memory.

Because of that, the fastest loop order is usually one where **`j` is the innermost loop**, such as:

- `i-k-j`
- `k-i-j`

These are faster because they access `B[k][j]` and `C[i][j]` contiguously in memory, which uses the cache efficiently.

The slowest orders are usually those with **`i` as the innermost loop**, such as:

- `j-k-i`
- `k-j-i`

These jump through memory with a large stride, so cache performance is worse.
