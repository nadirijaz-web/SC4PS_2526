# FFT Tutorial Homework Answers


## Part 1: Before running anything

### 1. What does an FFT tell you about a signal?
An FFT tells us how strongly different frequencies are present in a uniformly sampled signal. It transforms time-domain data into frequency-domain information, so we can identify the main oscillation frequencies and their amplitudes.

### 2. Difference between sampling rate, Nyquist frequency, and frequency resolution
- **Sampling rate** is the number of samples taken per second, denoted by $f_s$.
- **Nyquist frequency** is half the sampling rate:
  $f_N = \frac{f_s}{2}$
  It is the highest frequency that can be represented without aliasing.
- **Frequency resolution** is the spacing between FFT bins:
  $\Delta f = \frac{f_s}{N} = \frac{1}{T}$
  where $N$ is the number of samples and $T$ is the total record length.

### 3. Why is a uniformly spaced time grid important?
The FFT routine used in this project assumes equally spaced samples in time. If the time grid is not uniform, the standard FFT bin frequencies no longer match the sampled data correctly, so the resulting spectrum is not reliable.

## Part 3: Sampling and aliasing

### 1. The sampling frequency is given
$f_s = 128\,\mathrm{Hz}$.

### 2. What is the Nyquist frequency?
$f_N = \frac{f_s}{2} = \frac{128}{2} = 64\,\mathrm{Hz}$.

### 3. Why can a 120 Hz component not be reconstructed faithfully?
Because $120\,\mathrm{Hz} > 64\,\mathrm{Hz}$, so it lies above the Nyquist frequency. After sampling, that component folds back into the lower-frequency range and appears at a false frequency.

### 4. The program reports an aliased peak near 8 Hz

### 5. Why can a high-frequency signal appear as a false low-frequency signal?
Physically, sampling only records the signal at discrete times, so a rapidly oscillating signal can produce the same sampled values as a slower oscillation.

Mathematically, frequencies that differ by integer multiples of the sampling frequency can become indistinguishable after sampling. Here the aliased frequency is

$f_{\text{alias}} = |120 - 128| = 8\,\mathrm{Hz}$

So the true 120 Hz component appears in the sampled data as a false 8 Hz component.

## Part 4: Frequency resolution


### 1. The signal contains 50 Hz and 55 Hz

### 2. What is the total record length $T$?
- $N = 64$
- $f_s = 512\,\mathrm{Hz}$
- $\Delta t = 1/f_s = 1/512\,\mathrm{s}$

Therefore,

$T = N\Delta t = \frac{64}{512} = 0.125\,\mathrm{s}$.


### 3. What is the FFT bin spacing $\Delta f$?
$\Delta f = \frac{f_s}{N} = \frac{512}{64} = 8\,\mathrm{Hz}$.

### 4. Why does this make the two frequencies difficult to separate?
The two true frequencies differ by only **5 Hz**, but the FFT bins are spaced by **8 Hz**. That means the spectrum is too coarse to resolve them cleanly as two separate peaks.

### 5. What should be changed first to improve separation?
The first thing to change is **the total acquisition time**.

That is because the resolution obeys

$\Delta f = \frac{1}{T}$

A longer observation time makes $\Delta f$ smaller and improves the ability to separate nearby frequencies. Changing the plotting tool or output file format does not improve the underlying frequency resolution.

## Part 5: Coupled oscillators


### 1. Equations of motion
The code uses

$m\ddot{x}_1 = -(k + k_c)x_1 + k_c x_2$

$m\ddot{x}_2 = k_c x_1 - (k + k_c)x_2$

### 2. What physical system do these equations represent?
They represent two identical masses attached to walls by springs and coupled to each other by an additional spring.

### 3. What are the two normal modes?
The two normal modes are:
- the **in-phase mode** ($\omega_1=\sqrt {k/m}$), both masses move together.
- the **out-of-phase mode** ($\omega_2=\sqrt {(k+2k_c)/m}$), the masses move oppositely.


### 4. Why does the FFT of $x_1(t)$ show more than one important frequency?
Because the chosen initial condition excites a combination of both normal modes rather than only one pure mode. Therefore the motion of $x_1(t)$ contains contributions from both mode frequencies.

### 5. Why compare the numerical FFT peaks with theoretical normal-mode frequencies?
Because this checks whether the numerical simulation agrees with the analytical prediction.

## Part 8: Reflection

One thing I learned about FFTs from this project is that the FFT only reflects the sampled data, so poor sampling choices can create aliasing or poor frequency resolution even when the underlying continuous signal is simple.

One thing I learned about scientific software organization is that it is very useful to separate source code, shared utilities, generated outputs, and plotting scripts. That makes the workflow easier to understand and reproduce.
