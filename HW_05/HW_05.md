# Homework 05 - Legendre Polynomial Stability

This homework computes the ordinary Legendre polynomials $P_\ell(x)$ for
$\ell = 0,1,\dots,50$ and for

$$
x \in \{0.1,0.5,0.9,0.99\}.
$$

The goal is to compare a standard forward recurrence with a backward recurrence experiment, using high-precision reference values to measure the numerical errors.

## What is implemented

The code contains three parts:

1. **Forward recurrence**

   The computation starts from

   $$
   P_0(x)=1, \qquad P_1(x)=x,
   $$

   then uses Bonnet's three-term recurrence

   $$
   P_{\ell+1}(x)=\frac{(2\ell+1)xP_\ell(x)-\ell P_{\ell-1}(x)}{\ell+1},
   \qquad \ell \ge 1.
   $$

   This recurrence is evaluated in standard double precision.

2. **Backward recurrence**

   A Miller-style backward experiment is also performed.  The sequence is initialized at a larger index $L$ by

   $$
   \widetilde P_{L+1}(x)=0, \qquad \widetilde P_L(x)=1,
   $$

   and is propagated backward using

   $$
   \widetilde P_{\ell-1}(x)=
   \frac{(2\ell+1)x\widetilde P_\ell(x)-(\ell+1)\widetilde P_{\ell+1}(x)}{\ell},
   \qquad \ell=L,L-1,\dots,1.
   $$

   After the backward sweep, the sequence is rescaled by

   $$
   c=\frac{1}{\widetilde P_0(x)},
   \qquad
   P^{(\mathrm{back})}_\ell(x)=c\widetilde P_\ell(x).
   $$

   This normalization makes the backward sequence agree with $P_0(x)=1$, but it does not force the whole sequence to be the ordinary Legendre polynomial sequence.

3. **Reference values**

   The reference values are computed with `mpmath` using

   ```python
   mp.mp.dps = 100
   ```

   This gives 100 decimal digits of precision.  The double-precision forward and backward results are compared against these high-precision reference values.

## Output of the program

The program first writes the double-precision results to `results/double_values.csv`.
The high-precision post-processing script then writes `results/errors.csv`.
For each value of $x$ and each degree $\ell$, the error file contains:

- the high-precision reference value,
- the forward value,
- the backward value,
- the absolute error of the forward method,
- the relative error of the forward method,
- the absolute error of the backward method,
- the relative error of the backward method.

A second file, `results/summary.txt`, contains the maximum absolute and relative errors for each value of $x$.
The file `results/verification_checks.csv` records basic checks on the row count, high-precision setup, normalization, and expected error behavior.

## Plots

The Python plotting script reads `results/errors.csv` and creates two figures:

- `results/relative_error_panel.png`
- `results/absolute_error_panel.png`


## How to run the homework

From the project directory use:

```bash
make full
```

This does the following:

1. compiles the C files,
2. runs the executable,
3. generates the double-precision output,
4. computes the high-precision reference values and errors,
5. creates the plots.

To remove generated files, use:

```bash
make clean
```
