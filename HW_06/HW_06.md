# Homework 06

This program reads the required variables from a plain text input file, computes the vector operation

```text
D[i] = a * X[i] + Y[i]
```

and writes the result chunk by chunk to an HDF5 output file.

## Input file structure

The input file use the required `Variable = Value` structure:

```text
n = 1000000
a = 2.0
x_value = 3.0
y_value = 4.0
chunk_size = 100000
output_file = hw06_output.h5
```

The parser accepts spaces around `=` and ignores blank lines or lines beginning with `#`.

## Compile


```bash
make
```

## Run

```bash
./hw06 input.txt
```


## What the program produces

The HDF5 output file contains:

```text
/D
/chunk_sums
/parameters/n
/parameters/chunk_size
/parameters/num_chunks
/parameters/a
/parameters/x_value
/parameters/y_value
/parameters/operation
/checks/expected_value
/checks/first_value
/checks/global_sum
/checks/expected_global_sum
/checks/max_abs_error
```

The verification checks that:

```text
expected value = a*x_value + y_value
D[i] = expected value for every i
expected global sum = n*(a*x_value + y_value)
```

For the included example, `a = 2`, `x_value = 3`, and `y_value = 4`, so every element is `10`.
