# Homework 07 - Random Numbers

This homework solves five exercises about pseudo-random numbers and simple Monte Carlo methods:

1. Simulate 100,000 fair coin tosses and study the running fraction of heads.
2. Estimate pi with Monte Carlo sampling in the unit square.
3. Generate `Y = U^2` from uniform random numbers and compare with the analytic density.
4. Generate exponential random variables using inverse transform sampling with `lambda = 1.5`.
5. Plot the empirical CDF of the exponential sample and compare it with the exact CDF.

The random number generator and all numerical computations are implemented in C. The Python script only reads the C-generated data files and creates the plots.

## Files

- `homework07.c`: main C program for the five exercises.
- `rng.c`, `rng.h`: linear congruential generator used by the exercises.
- `Makefile`: compile and run commands.
- `plot_results.py`: plotting script for the generated data.
- `output/report.txt`: numerical results and short comments.
- `figures/`: generated plot images.

## How to run

Compile the C program:

```sh
make
```

Run the homework program:

```sh
make run
```

Generate all plots:

```sh
make plots
```

Clean generated files:

```sh
make clean
```

After `make plots`, the numerical report is saved in `output/report.txt` and the plots are saved in `figures/`.
